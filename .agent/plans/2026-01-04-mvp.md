## Purpose / Big Picture

After this change, a user can add a home screen widget that shows how far through the current year they are using a minimalist grid of dots, plus a footer with the year and day count (for example “2026” and “4/365”). The widget updates daily around midnight and can be manually refreshed by tapping it, so the display stays accurate without opening the app. You can see it working by placing the widget on the launcher and verifying that the dot count and footer reflect today’s date.

## Context and Orientation

This repository is a bare Android app with a minimal `AndroidManifest.xml`. The Gradle module is `app` with namespace `com.example.koyomidots`. New Kotlin sources now live under `app/src/main/java/com/example/koyomidots/` following the layered packages `data/`, `domain/`, `ui/`, and `di/`, but dependencies, tests, and manifest registrations still need to be added. The widget is implemented using Jetpack Glance (the AndroidX library for AppWidgets in a Compose-like style). “Worker” refers to a class managed by AndroidX WorkManager that runs code periodically in the background, even if the app is not open. “Glance state” refers to key/value storage used to supply data to widgets.

## Plan of Work

First, add the required dependencies for Glance, WorkManager, Coroutines, and testing libraries to `gradle/libs.versions.toml` and `app/build.gradle.kts`. This makes the libraries available for widget rendering, background scheduling, and unit tests.

Next, create the Data layer in `app/src/main/java/com/example/koyomidots/data/` with a `TimeDataSource` interface and a `SystemTimeDataSource` implementation that wraps `LocalDate.now()`. This abstraction allows deterministic testing.

Then, implement the Domain layer in `app/src/main/java/com/example/koyomidots/domain/`. Add a `YearProgressModel` data class and a `GetYearProgressUseCase` that reads from `TimeDataSource`, calculates leap years and day-of-year values, computes a progress percentage, and formats the footer string. This layer must not import any Android classes.

After the domain logic, write unit tests under `app/src/test/java/com/example/koyomidots/domain/` to validate standard year behavior, leap year handling, and formatting. Use JUnit4 with MockK or a simple fake data source, and assert using Truth.
When designing unit tests, explicitly apply appropriate test design techniques such as Equivalence Partitioning and Boundary Value Analysis, and briefly note which technique each test case covers so coverage is intentional rather than incidental.

Then, implement the UI layer in `app/src/main/java/com/example/koyomidots/ui/` with a `YearProgressWidget` (Glance widget), a `YearProgressWidgetReceiver` (AppWidget receiver), and a `WidgetUpdateWorker` (WorkManager). The worker runs the use case, writes the results to Glance preferences state, and asks the widget to update. The widget reads state and renders the dot grid and footer in the Moleskine theme using `ColorProvider` for light/dark modes.

Add a small DI entry point in `app/src/main/java/com/example/koyomidots/di/` that provides singletons for the data source and use case. Create an `Application` subclass that initializes dependencies and schedules the periodic worker with an initial delay aligned to the next midnight.

Finally, register the widget receiver, application class, and AppWidget provider XML in the manifest and `res/xml/`. Validate behavior by running unit tests and adding the widget on a device/emulator.

## Validation and Acceptance

A human can verify success by doing all of the following:

1. Run the unit tests and confirm that the year-progress tests pass.
2. Install the debug app on an emulator or device.
3. Add the “Year Progress” widget to the home screen.
4. Observe the dot grid: the number of “active” dots (past days) should equal today’s day-of-year, and “inactive” dots should be the remaining days in the year.
5. Observe the footer: left side shows the current year (for example “2026”), right side shows “<day>/<total>” (for example “4/365” on January 4, 2026).
6. Tap the widget and confirm it refreshes (you can temporarily change the system date or temporarily stub the data source in debug to see the update).
7. Leave the device until after midnight and confirm the widget updates without opening the app.

Acceptance is met when the widget renders correctly in both light and dark modes, updates daily, and unit tests validate leap year and formatting logic.

The calculation rules inside `execute()` must be:

- `today` is from `timeDataSource.today()`.
- `year` is `today.year`.
- `totalDays` is `if (today.isLeapYear) 366 else 365`.
- `currentDay` is `today.dayOfYear` (1-based).
- `progressPercentage` is `(currentDay.toDouble() / totalDays.toDouble() * 100).roundToInt()`.
- `formattedString` is `"$currentDay/$totalDays"`.
